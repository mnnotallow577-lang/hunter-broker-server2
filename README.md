# Hunter Broker server

One shared, SIMULATED price feed for every device, a candle API, and the web app.
No real market data. No real money. Needs Node.js 18 or newer. No npm install needed.

## Run
    node server.js            # http://localhost:8080  (web app + API)

Environment variables (all optional)
- PORT      port to listen on (default 8080)
- API_KEY   if set, API calls from outside the app need the key (header `x-api-key` or `?key=`)
- DATA_DIR  where state.json is saved every 5 minutes (default ./data). Keeps the feed continuous after restarts.

## Put it online (so phones can reach it)
Use any host that runs Node: Render, Railway, Fly.io, a small VPS.
Start command: `node server.js`. Free tiers usually sleep when idle and may erase the disk,
so the feed pauses or restarts there. Use an always-on plan or a VPS for a continuous feed.
After deploy, open the address on your phone, then install it (Android Chrome: menu > Install app,
iPhone Safari: Share > Add to Home Screen).

If you host the app files somewhere else, open the app > Settings > "Price server (optional)",
paste your server address, and press "Save and reload".

## API (JSON, all GET)
- /api/pairs                         all pairs: price, payouts (1+ min, 5+ min), sentiment, 3h change
- /api/price?pair=EUR/USD            latest price
- /api/prices                        latest price of every pair
- /api/candles?pair=EUR/USD&tf=60&limit=200[&before=UNIX_SECONDS]
                                     tf in seconds (5..14400), limit up to 2000, newest last, `live:true` = still forming
- /api/ticks?pair=EUR/USD&seconds=10800[&before=UNIX_SECONDS]   one price per second, compact
- /api/analysis?pair=EUR/USD&tf=60   RSI14, EMA20/50, ATR14, candle patterns, nearest support/resistance
- /api/stream?pairs=EUR/USD,GBP/USD  live updates (Server-Sent Events, 4 per second) + payout changes
- /healthz                           health check

Pair names with spaces must be URL-encoded, e.g. `USD/IDR%20(OTC)`.

## Telegram bot example
    BOT_TOKEN=... API_URL=https://your-server.com API_KEY=... node bot-example.js
Commands: /pairs /price /candles /analysis /signal. The /signal rule is a toy for testing.

## Please note
All prices are generated by this server. They are not Quotex prices or any real market's prices,
so nothing built on this feed can predict a real market. Label anything you publish from it as simulated.
